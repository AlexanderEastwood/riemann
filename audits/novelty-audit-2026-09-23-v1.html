One proposed escape also repeats the problem

A trace normalization on the positive matrix is ineffective if we still optimize a free step size. Dividing the matrix by its trace shrinks the direction; multiplying the step by that trace restores exactly the same update.

Best line gain = ⟨residual, direction⟩² / ‖direction‖²

This ratio is unchanged by scaling the direction. Trace-one rank-one pairs still give both signs of each available individual LCM observation. A bound on the actual total update, with no scale subsequently restored, is a different restriction. No estimate for that restricted construction is proved here.

What changes in the work plan

Stop treating positivity rephrasings and free-scale normalizations as new directions. Before pursuing a variation, compare it with the nearest recorded result and identify the particular arithmetic term for which a stronger estimate is proposed.

The existing primary target is a lower bound on the complete joint observation energy of the actual optimized residual. A gain comparable to a/j after j doublings is a possible sufficient scale; an eventual fixed fraction at every doubling is already excluded. Restating this target is not itself progress.

This audit supplies no new cofinal estimate. It corrects the description and screens out a redundant continuation. It adds no theorem node or manuscript version, and preserves the earlier proof records.
