The quantity that must survive the transfer

Keep the prescribed coefficients dn = −μ(n) log(2N/n) for N < n ≤ 2N, without rescaling. With the complete old/new Gram blocks,

HN = D − CTG−1C,
KN = dTHNd.

The sufficient cost target is a constant upper bound for

on all sufficiently large dyadic J. The diagonal contribution is already bounded. The unresolved part is the signed cross sum containing the full matrix HN. Removing its old-space subtraction replaces the problem with a larger sufficient budget. NS98: exact target and stop record.

Tao: fixed shifts do not settle the growing sum

Write the projected cross term as a sum over shifts:

CNproj = 2 ∑h=1N−1 ∑m=N+12N−h μ(m)μ(m+h)LN(m)LN(m+h)HN(m,m+h),
where LN(m) = log(2N/m).

Elementary scope check: positivity of HN and NS98’s existing diagonal bound imply

|HN(m,n)| ≤ 4κ/√(mn),
∑1≤h≤L |CN,hproj| ≤ 8κ(log 2)2L.

Here κ = log(2π) − γ, and each fixed-shift sum has at most N terms, each bounded using m,n > N. Thus every fixed finite collection of shifts already has bounded cost, without a Möbius-cancellation theorem. This is bookkeeping from the inherited bound, not a new arithmetic estimate. Letting L grow destroys that constant bound.

The missing transfer must therefore handle growing shifts and the changing projected weights together. Summation by parts would require control of the variation of 2mLN(m)LN(m+h)HN(m,m+h), with errors summable over the shifts. No such control is supplied here.

Averaging in j does create a long logarithmic range of integers, so the fixed-ratio mismatch alone does not dispose of that possibility. But each doubling changes the projection and taper, and the number of shifts grows. A uniform weighted transfer and a total error budget would still have to be established. Applying a fixed-shift limit and then summing a growing set of shifts is not justified.

Short intervals: the scale is too weak for the proposed substitution

NS92’s larger scalar budget is

KN ≤ κ log(2) SN,
SN = ∫N2N |∑x<n≤2N μ(n) log(2N/n)/n|2 dx.

To expose the normalization, put v(u) = log(2/u)/u and RN(u) = ∑Nu<n≤2N μ(n)v(n/N). A change of variable gives the exact bookkeeping identity

SN = (1/N) ∫12 |RN(u)|2 du = N eN,
eN := ∫12 |RN(u)/N|2 du.

Pointwise bounded scalar cost would follow from eN = O(1/N). The actual averaged target only needs bounded means of 2je2j, which is weaker than that pointwise demand. Qualitative cancellation eN → 0 does not supply either bound.

Even an optimistic transfer giving eN ≤ C/(log N)c would leave an upper allowance CN/(log N)c. Averaging that allowance over J ≤ j < 2J still grows. This is a limitation of that upper bound; it is not evidence that the actual cost grows.

There is also a domain mismatch before any rate comparison: RN uses varying-length suffixes with a common endpoint. An almost-everywhere statement for each fixed interval length cannot automatically be evaluated along the variable length 2N−x. Nor does a small exceptional set guarantee that selected dyadic endpoints avoid it. The paper’s long-average term and, for Theorem 3, the excluded integers would also need accounting. None is discarded in this audit. NS92 already records the stronger square-root oscillation requirement for its supremum bound.

Controls, companion input and disposition

This is a theorem-applicability audit, exempt from claiming a new research row. It proposes no new sufficient RH inequality to certify or scan. Davenport–Heilbronn and the NS100/101 theta controls do not carry the stipulated Möbius reciprocal-Euler coefficients together with this exact fractional-part Gram family; importing their coefficients would change the problem. They are marked not applicable to the proposed literal transfer, not counted as passed tests. No unchanged example screen was run.

The existing NS74 unitary control preserves the whole Gram, hence every projected cost, while changing the target-approximation behavior. It reinforces the existing requirement to prove a compatible lower numerator separately. NS93’s sufficient pair remains: bounded averaged cost and a positive averaged normalized lower numerator. A cost theorem alone would not complete that argument.

Decision: stop direct substitution of these two theorem families. A follow-up would need a concrete uniform estimate for the growing-shift sum with the actual projection retained, or a justified interval-energy transfer with a sufficient total error budget. Neither has been obtained. That requirement restates the same open input; it is not a newly opened route.
