A bounded test.
No pole candidate.

Six agents implemented, checked and reviewed the original theta quotient search. None of the four selected refinements reached the fixed root threshold. The result is inconclusive.

Wall check: Distinct test. Closest results: PR78–79. A verified uncancelled denominator zero would reject the general quotient-positivity construction. This search found no such candidate. The original signed theta estimate remains the same open gap.

What we tested

The quotient is k=C/M, where M integrates the product of two shifted original theta kernels and C integrates the same product weighted by the square of the integration variable. A zero of M matters only if C does not cancel it.

The protocol was recorded in PR80 before the original calculation. It fixed one rectangle:

1/8 <= Re(z) <= 2
1/8 <= Im(z) <= 5/8

The run used 81 initial points, four selected cells and 128/256-bit replays. Refinements were required to remain inside their selected cells. All four stopped at those boundaries.

Residual means the normalized denominator magnitude divided by the largest corner value in the same cell. The candidate threshold was 2^-40, about 0.00000000000091. These four residuals are sampled values, not regional lower bounds.

Checks that mattered

The same locator found a known pole in a synthetic control. With the same denominator but a canceling numerator, it did not flag an uncancelled pole. This checked the distinction the original test needs.

A separate implementation then checked exactly the four saved endpoints using direct theta terms and a different integration method. M, C and the denominator derivative agreed to better than 1.41e-26 in relative terms at those points. No extra region or root search was added.

Diagnostic, not certified. Complete lattice and integration-tail formulas are retained. Numerical integration and rounding errors are not enclosed by interval arithmetic. Agreement between methods is useful validation, but it does not prove an exact zero, its absence, or a sign.

Where this leaves us

General positive definiteness of C/M remains undecided. The original first-Laguerre inequality remains open. Even a future verified pole would reject only this sufficient quotient construction; it would not refute that original inequality.

Stop this bounded test. There is no candidate to certify and no basis here for automatically widening the search. Further work needs a separate arithmetic estimate or a new, specified test with its own decision and controls. No such estimate was obtained in this run.

No new research row, thaw, theorem node or manuscript version. The two missing historical evidence groups remain open.
