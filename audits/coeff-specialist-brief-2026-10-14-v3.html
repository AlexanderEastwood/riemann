Can a directional or dual extractor see the actual Nyman–Beurling optimizer?

We have an unconditional n−4-weighted coefficient bound and an exact compact dual-extractor reduction on the dyadic increment space, while universal n−3 recovery is ruled out by adjacent second differences. Could you identify an unconditional arithmetic estimate for a directional residual pairing—or a specific reason this coefficient/extractor route is the wrong next step?

1. The narrowed question we need answered

In the smoothed q = 2 Nyman–Beurling problem, can one construct a test direction w ∈ ℝN on the new dyadic block (or equivalently a compact dual test ψN inducing w = S−1λ̃N) whose Schur-complement energy wTSw is controlled and whose pairing |wTh| with the residualized target load admits an unconditional positive arithmetic lower bound?

Two structural facts proved since v2 narrow the search space:

  • Universal n−3 norm recovery on V2N ∩ VN⊥ is false (NS61): any improvement over the n−4 weight must be directional or target-aware, not a uniform norm inequality over all residualized coefficient vectors.
  • Compact dual extractors avoid low-old alias truncation and the NS78 constant B: for any target-orthogonal dual test ψN, the untruncated pairing MN(u, y) = λ̃NTy is algebraically identical to the Schur–Rayleigh quotient along w = S−1λ̃N, with exact denominator bound λ̃NTS−1λ̃N ≤ ‖ψN‖2 = CbN and direct NS87 transfer at physical cutoff T = N6.

2. Fixed problem and exact Schur-complement gain

Fix smoothing order q = 2 and the complete Hilbert space H = L2((0, ∞), dt/t2). The target and integer atoms are

τ(t) = 1t≥1 log t,
an(t) = A(t/n),   A(z) = ∫0z {u} du/u.

Let ΠN be orthogonal projection onto VN = span{a1, …, aN}, rN = (I − ΠN)τ, and EN = ‖rN‖2. For the dyadic extension from N to 2N, partition the 2N × 2N Gram matrix into old/old, old/new, and new/new blocks G, C, D (indices 1, …, N and N + 1, …, 2N), and split the target load bn = ⟨τ, an⟩ into bold and bnew. Then

S = D − CTG−1C,   h = bnew − CTG−1bold,
y = S−1h,   u = −G−1Cy,
ΔN = EN − E2N = yTSy = hTS−1h.

Here rN − r2N = ∑m≤N umam + ∑N<n≤2N ynan ∈ V2N ∩ VN⊥ is the exact optimizer increment. A cofinal, nonnegative, nonsummable lower bound for the relative gains Δ2j / E2j forces EN → 0 and hence RH by the fixed q = 2 criterion (NS61). No such lower bound is established here.

3. Why universal n−3 recovery is ruled out (NS61)

NS78’s exact divisor inversion gives the unconditional n−4-weighted lower bound

ΔN ≥ (1/B) (∑m≤N |um|2/m4 + ∑N<n≤2N |yn|2/n4),   B = 1536 ζ(2)2.

Because a heuristic Möbius assignment yn = −μ(n) gives ∑N<n≤2N μ(n)2/n4 asymp; N−3 (summable against EN ≳ 1/log N), a natural question is whether residualization onto V2N ∩ VN⊥ upgrades the exponent from n−4 to a universal n−3 recovery inequality ∑N<n≤2N |yn|2/n3 ≤ C3 yTSy.

Refutation on V2N ∩ VN⊥: In NS61 (where an corresponds to nσn), the first-difference vectors εn = σn − ((n − 1)/n)σn−1 satisfy nεn = ∫n−1n h1(u·) du and n3‖εn‖2 → κ = log(2π) − γ. Forming the adjacent second difference for N + 2 ≤ n ≤ 2N − 1,

Wn := εn+1 − (n/(n + 1))εn = σn+1 − (2n/(n + 1))σn + ((n − 1)/(n + 1))σn−1,

strong continuity of dilations on L2 gives n3‖Wn‖2 → 0 as n → ∞, while its three nonzero new-block coordinates (supported entirely in {N + 1, …, 2N}) satisfy ∑k=N+12N |yk|2/k3 ∼ 6/n3. Since orthogonal projection onto VN⊥ only decreases norm (‖(I − ΠN)Wn‖2 ≤ ‖Wn‖2 = o(n−3)), the Rayleigh quotient (yTSy) / (∑ |yk|2/k3) tends to 0. In addition, the Hedenmalm–Lindqvist–Seip multiplier identity on ℓ2(n−4) has exact squared norm Cμ = ζ(2)/ζ(4) = 15/π2: retaining squarefree support sharpens the constant from ζ(2)2 to ζ(2)/ζ(4), while Möbius signs give no further unrestricted operator-norm saving.

4. Exact compact dual extractor and untruncated Schur–Rayleigh reduction

Instead of a universal weighted norm bound, let b(s) = (s − 1)3(2 − s)3(2s − 3)1[1,2](s), βN(t) = N−1b(t/N) on [N, 2N], and define the compact dual extractor

ψN(t) := −t2(tβ′N(t))′ ∈ Cc1([N, 2N]) ⊂ H.

Because ∫12 b(s) ds = 0 and b vanishes to order 3 at s = 1, 2, integration by parts gives ⟨τ, ψN⟩H = 0 and exact atom pairings λj := ⟨aj, ψN⟩H = ∑k≥1 βN(kj). Consequently:

  • Exact new-block diagonalization: for N < n ≤ 2N, only k = 1 lies in (N, 2N), so (λnew)n = βN(n) = N−1b(n/N).
  • Exact fourth-order Euler–Maclaurin old-alias decay: for 1 ≤ m ≤ N, |(λold)m| ≤ Ab(m/N)3 with exact rational constant Ab = (2ζ(4)/(2π)4) Varℝ(b‴) = 181 / 3360 ≈ 0.053869, where Varℝ(b‴) = 543 / 14 (and ∫12 s4b(s)2 ds = 1219 / 38798760).
  • Untruncated Schur–Rayleigh equivalence: on any residualized increment f = ∑m≤N umam + ∑N<n≤2N ynan ∈ V2N ∩ VN⊥ (where u = −G−1Cy), the untruncated linear functional is
    MN(u, y) := ⟨f, ψN⟩H = λoldTu + λnewTy = (λnew − CTG−1λold)Ty =: λ̃NTy.
    By Bessel’s inequality on the orthogonal decomposition V2N = VN ⊕ (V2N ∩ VN⊥), the dual norm of MN on V2N ∩ VN⊥ is bounded without any low-old truncation at K = ⌊√N⌋ by
    λ̃NTS−1λ̃N = ‖(Π2N − ΠN)ψN‖H2 ≤ ‖ψN‖H2 − λoldTG−1λold ≤ CbN,   Cb = 6904 / 45045 ≈ 0.153269.
    For the actual optimizer increment y = S−1h, setting wψN := S−1λ̃N gives
    MN(u, y) = λ̃NTS−1h = wψNTh = ⟨(Π2N − ΠN)ψN, τ⟩H,
    ΔN = hTS−1h ≥ (wψNTh)2 / (wψNTSwψN) = (λ̃NTS−1h)2 / (λ̃NTS−1λ̃N) ≥ |MN(u, y)|2 / (CbN).
  • Direct NS87 tail transfer without B = 1536 ζ(2)2: for the finite-observation residual load ĥN,T = qnew(T) − CTG−1qold(T) at physical cutoff T = N6, Cauchy–Schwarz in S−1 gives directly
    |MN(u, y) − λ̃NTS−1ĥN,T| / √(CbN) ≤ ‖h − ĥN,T‖S−1 = O(N−1/2 log2N) · EN1/2.

This clarifies what a dual extractor achieves and what remains open: ψN supplies a proved O(N) upper bound on the denominator wTSw = λ̃NTS−1λ̃N ≤ CbN, while the numerator MN(u, y) = λ̃NTS−1h = ⟨(Π2N − ΠN)ψN, τ⟩H still requires an arithmetic lower bound on the off-diagonal projection of ψN onto the residual target rN.

5. Existing constraints an answer must respect

NS80 already retains generic Gram conditioning. Its complete sampling Gram Q satisfies Q/16 ≤ G ≤ 21Q/16, with the same constants on Schur complements; another generic conditioning improvement leaves the numerator pairing unestimated.

NS74 tests target dependence. Its unitary altered family preserves every Gram entry (hence G, C, D, S, and λ̃NTS−1λ̃N) while altering the target loads bold, bnew and has a positive error floor. Any lower bound on |wTh| must use an arithmetic property specific to the original target loads bn = ⟨τ, an⟩.

NS83 restricts asymptotic gain rates. Eventual Δ2j / E2j ≥ a / j with a > 1 (i.e. ΔN ≥ κEN / log N with κ > log 2) is excluded; 0 < a ≤ 1 remains a compatible sufficient rate.

6. What a useful specialist response would look like

Please identify one candidate lemma, or explain why no unconditional directional lower bound is currently within reach. For a candidate lemma, we need:

  1. The exact direction w ∈ ℝN (or dual test ψN) and the stated inequality with all quantifiers.
  2. How the denominator wTSw (or λ̃NTS−1λ̃N) is bounded without unproved spectral assumptions on S−1.
  3. The specific method for lower-bounding the residual load pairing |wTh| = |wT(bnew − CTG−1bold)|, and the exact property of the original target loads bn that distinguishes it from the NS74 control.
  4. For any imported theorem, an arXiv/literature citation and a line-by-line verification of its hypotheses.
  5. The transfer to ΔN / EN, any remaining unproved companion estimate, and the fastest cheap test to falsify the proposal.

A clear negative assessment explaining why ⟨(Π2N − ΠN)ψN, τ⟩H cannot be lower-bounded without first controlling the full inverse Gram G−1bold would be equally valuable. No numerical scan or proof campaign is authorized by this brief before review and Alex’s approval.
