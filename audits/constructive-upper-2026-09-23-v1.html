A restriction we can impose without losing the rate

We can require the approximating function to vanish exactly for x > 1 by imposing the single coefficient constraint ∑cn/n = 0. This changes the approximation itself; it does not discard part of its error.

For every N ≥ 256, the best normalized squared error satisfies
EN ≤ EN0 ≤ 1.144579 EN.

This preserves any possible logarithmic decay exponent. It compares two errors whose limiting behavior is unknown; it does not show that either tends to zero.

The exact normalization cost is ηN2/qN, where ηN = ∑cn/n and qN is the squared length of the exterior-tail function’s projection onto the first N atoms. Projection gives EN0 ≤ EN/qN. The qN increase with N, so the certified size-256 comparison holds at every later size.

The remaining arithmetic estimate

The complete upper certificate consists of the exact signed divisor-cell energy up to a cutoff, followed by the logarithmic main tail and an explicit bound for the entire remainder, including its cross term. The remote region near x = 0 remains included.

To prove the candidate upper rate, we still need an explicit family of coefficients and a uniform bound on that complete quantity by C / log N. The finite table and the normalization comparison do not provide this missing estimate. The present optimized coefficients still require complete Gram solves; no fast algorithm or closed-form family is supplied.
