`RH_G1_G2_research_log.md`, and `v1_revision_notes.md` at the repository root.
Keep current evidence and provenance linked from the root README. Archive
superseded supporting files; do not present an old PDF as a live manuscript.

new PDFs unless the author explicitly requests them again.
