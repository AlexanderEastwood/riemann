# Reproduce v1.17: complete ground ordering at lambda=3

The full manuscript is at the archive root. Extract the complete cumulative ZIP before running these commands; the current scripts use the retained sibling directories `g2_schur_directional`, `g2_certificate` and `g2_source_certificate`.

Dependencies: Python 3, python-flint 0.9.0 (FLINT 3.6.0 used for the recorded runs); LaTeX/latexmk for the PDF. All decisive certificate arithmetic is outward Arb arithmetic. No floating-point eigenvalue is an input to the proof.

From `g2_ground_order/`:

```sh
python3 certify_shifted_inertia.py --N 256 --M 512 --J 4096 --r 80 --parity even --bits 768 --diagonal --shift 1e-34 --witness ../g2_schur_directional/schur_witness_N256_M512_even_b768.json.gz
python3 certify_shifted_inertia.py --N 512 --M 1024 --J 4096 --r 100 --parity odd --bits 768 --diagonal --shift 1e-36 --witness ../g2_schur_directional/schur_witness_N512_M1024_odd_b768.json.gz
```

Repeat each command with `--bits 896`, retaining its same `--witness` path. The results must have status `inertia_certified`, 257 even pivots with exactly one negative (index24), and 512 positive odd pivots. Every pivot must exclude zero. The script recomputes all middle residual rows and bounds every remote row. The returned inertia is that of a lower Schur form; a negative pivot alone is not an actual negative Weil direction.

Then run:

```sh
python3 certify_trial_reuse.py
python3 certify_ground_overlap_constants.py
```
