RIEMANN PROJECT · NS-59 · SEPTEMBER 22, 2026 · VERSION 1

An improved block bound, with an arithmetic limit

We have an unconditional estimate for a complete Nyman–Beurling block. Its remaining lower-correlation requirement is open. RH is not proved.

What the calculation uncovered

The existing raw-trace estimate loses most of the available improvement on some finite blocks. At N = 128 and N = 256, it captures less than one four-hundredth of the true gain. Both statements were checked with interval arithmetic at two precisions, retaining all interactions with the previous approximation.

Adjacent dilation differences have much smaller individual norms. We proved, for every n ≥ 2,

Hn−1/n² − (n−1)/n³ ≤ ‖δn‖² ≤ Hn−1/n²,
where δn = ρn − (n−1)ρn−1/n.

The coordinate change also changes the correlations. Keeping that change is essential: at N = 256 the new trace bound is actually smaller than the original trace bound. The smaller denominator alone gives the wrong impression.

A complete asymptotic estimate

An exact Mellin-transform identity expresses the energy of the entire difference block as a zeta-weighted integral. A fractional Sobolev estimate accounts for every jump of the corresponding step function. The classical Weyl bound then gives

‖𝒟N‖ ≤ CεN−5/3+ε.

This is an analytic bound with an unspecified constant. It is stronger than the elementary trace budget asymptotically, but it still needs a lower estimate for the actual residual correlations.

Where uniform bounds run into arithmetic

For the raw block, a bound CεN−2+ε for every ε > 0 is equivalent to the Lindelöf hypothesis. A bound C(log N)B/N² for any fixed B is false: it would contradict established large values of zeta. These assertions hold even when only dyadic blocks are used.

The scope matters. These conclusions concern the raw Gram matrix over every possible coefficient vector. They do not establish the same obstruction for the projected matrix or for the particular direction selected by the optimal residual.
